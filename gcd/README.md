# GCD

**Time limit:** 1 second · **Memory limit:** 64 MB

Write a function that takes two numbers and computes their greatest common divisor (GCD) **recursively**.

A non-recursive solution earns no credit.

## Input

A single line containing the non-negative integers `n` and `m`.

`0 ≤ n, m ≤ 10⁶`

## Output

Print the GCD of the two input numbers on one line.

## Examples

| Input | Output |
|-------|--------|
| `36 24` | `12` |
| `8 9` | `1` |
| `0 5` | `5` |

*Hint:* the final implementation is very simple. What matters is how you think about it.
