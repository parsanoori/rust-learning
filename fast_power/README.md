# Fast Power

**Time limit:** 1 second · **Memory limit:** 64 MB

Write a function that takes two numbers `n` and `m` and computes `n^m mod (10⁹ + 7)` quickly and recursively. Then write a program that reads the two numbers from input and prints the result.

*The challenge here is the time limit — you need to find a correct method that runs within it.*

## Input

A single line containing two integers `n` and `m`, separated by a space.

`0 ≤ n, m ≤ 10⁹`

## Output

Print `n^m mod (10⁹ + 7)` on one line.

## Examples

| Input | Output |
|-------|--------|
| `99 9999999` | `758334627` |
| `4568 34895428` | `854539362` |
